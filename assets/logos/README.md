# 구단 로고

파일명을 `config/brand.yml` 의 `teams:` 키와 정확히 일치시켜 주세요.
확장자는 `.png` 권장이지만 `.jpg` / `.jpeg` / `.svg` 도 자동 인식됩니다
(`_logo_url()` 이 순서대로 확인함).

```
assets/logos/
├─ 삼성.png
├─ LG.png
├─ KT.png
├─ KIA.png
├─ 두산.png
├─ 한화.png
├─ NC.png
├─ 롯데.png
├─ SSG.png
└─ 키움.png
```

기본 9개 구단은 사용자가 보유한 구단 로고 모음 AI(일러스트레이터, PDF 호환) 파일에서
Ghostscript/pdftoppm 으로 300dpi 래스터화 후 개별 로고 영역을 크롭한 것입니다.
(원본: `2023년현재프로야구구단로고.ai`, 각 구단 공식 엠블럼과 동일한 디자인)

예외:
- **두산.png**: AI 파일의 로고는 2010~2024년까지 쓰인 구버전("DOOSAN BEARS SEOUL" 원형 배지).
  두산은 2025년 1월 15년 만에 BI를 전면 교체했다(다이아몬드 + 야구공 스티치 + "Bears" 스크립트,
  위/아래 "DOOSAN"/"SEOUL" 리본). 공식 사이트(doosanbears.com) 헤더 로고(`images/logo.svg`)를
  직접 캡처해서 교체함.
- **한화.png**: AI 파일도 구버전(주황/검정 "Eagles" 와드마크). 한화는 2025시즌부터 18년 만에
  로고를 교체(미네소타 트윈스풍 스크립트 로고). 위키백과 `Hanwha_Eagles_2025.png`로 교체함.
- **롯데.png**: 확인 결과 2023년 남색+빨강 리브랜딩 이후 엠블럼 변경 없음(AI 파일 그대로 최신).
- 나머지 7개 구단(삼성/LG/KT/KIA/NC/SSG/키움)은 최근 로고 변경 없음, AI 파일 그대로 사용.

더 고화질·투명 배경이 필요하면 각 구단 공식 사이트의 브랜드 가이드/보도자료 이미지로 교체하세요.

권장 규격: 정사각형, 256×256 이상. 투명 배경(PNG)이면 더 깔끔하지만 필수는 아닙니다
(불투명 배경이면 카드 배경색과 겹쳐 사각형 테두리가 살짝 보일 수 있음 — 현재 파일들은
흰 배경의 불투명 PNG).

파일이 없으면 렌더러가 자동으로 팀 컬러 스와치(색 막대)로 대체하므로 발행은 멈추지 않습니다.
로고를 아예 쓰지 않으려면 `config/brand.yml` 의 `logos.enabled: false`.
