# 뉴스카드 사진 폴더

여기에 넣은 사진만 뉴스형 카드에 쓰입니다. 자동 수집은 하지 않습니다.

## 파일명 규칙

```
원태인.jpg                          기본
원태인__center-30.jpg               사진 위치 조정 (center 30%)
원태인__연합뉴스.jpg                 출처 표기
원태인__center-30__연합뉴스.jpg      둘 다
```

- 파일명 앞부분(`__` 앞)이 카드가 찾는 키(slug)입니다. 보통 선수명.
- 위치 토큰: `top-20`, `center-30`, `bottom-10` 형식 → CSS background-position.
  인물 얼굴이 잘리면 이 숫자를 조정하세요. 기본값은 `center 22%`.
- 확장자: jpg / jpeg / png / webp

## 사진 고를 때

이 포맷은 사진이 헤드라인 감정선과 맞아야 삽니다.
"고개 숙인 뒷모습", "노려보는 장면" 처럼 문구가 말하려는 감정이
사진에 이미 들어있는 컷을 고르세요. 무표정 정면샷은 후킹이 죽습니다.

권장 해상도: 가로 1080px 이상, 세로로 긴 사진이 더 잘 맞습니다.
